# 公开开发预览快照

公开仓库：<https://github.com/solarise94/cloud2api-public>。

本次公开发布从审查后的当前文件快照建立新的 Git 仓库。初始 `main` 只有一个没有父提交的根提交，不导入原开发仓库的 Git 对象、提交、分支或标签。后续公开维护可以在这个新起点上继续提交；这不意味着项目以后不能保留公开开发历史。

## 发布范围

包含：

- cloud2api 源码、静态页面及使用合成数据的自动化测试。
- 不含实际凭据的示例配置、构建和部署脚本。
- 当前使用、接口及贡献文档。
- OpenList 派生补丁、固定上游版本信息和 AGPL-3.0 许可证文本。

不包含：

- 原仓库的 `.git`、旧提交作者邮箱、历史分支和标签。
- 实际 `config.yaml`、环境文件、网盘内容、运行目录和密码文件。
- 数据库、日志、备份、容器检查结果和本机部署工具。
- 内部设计时间线、实施计划和历史升级笔记。
- 本机镜像、容器卷、构建缓存或真实账号测试附件。

新根提交使用公开 GitHub 用户名及 `noreply` 邮箱，不沿用开发仓库中的私人提交邮箱。发布附件通过 `git archive` 从公开根提交生成，不从包含运行数据的工作目录直接打包。

## 隐私检查与复核

发布文件采用明确的文件清单导出，不使用整目录复制。导出时拒绝符号链接、路径逃逸、运行数据目录和敏感文件类型；随后检查最终文件内容、Git 树和提交元数据。示例与测试中的固定字符串应仅用于合成夹具，不能替换为自己的凭据后再提交。

本次使用 Gitleaks 8.24.3 的默认规则扫描导出目录，原始命中为 8 处合成测试值及 1 处上游主动公开的百度手动登录应用参数；逐项核对后未发现实际部署凭据。公开参数已与 [OpenList-APIPages 源码](https://github.com/OpenListTeam/OpenList-APIPages/blob/581b57aa/frontend/src/pages/TokenPage.tsx#L118-L124) 比对，不将其误当作本机账号密钥。`.gitleaksignore` 仅记录这些特定文件、规则和行号，不排除整个测试目录或所有凭据规则。

可在仓库根目录复核：

```sh
gitleaks dir . --redact=100 --gitleaks-ignore-path .gitleaksignore
```

Logo 的图像来源凭证予以保留；它描述生成来源，不包含网盘账号凭据。

自动扫描和人工复核只能降低风险，不能保证不存在未知敏感信息。发现疑似凭据时，请勿将原文贴到公开 Issue；应先撤销或轮换对应凭据，再处理公开内容及其缓存。

## 验证边界

Go 与前端自动化测试使用隔离夹具，不在真实网盘上进行上传、删除或故障注入。模拟测试通过不代表所有网盘账号类型、长期续期及故障恢复均已验证；具体平台范围见 [平台矩阵](../openlist-patch/docs/PLATFORMS.md)。

剪贴板兼容修复有自动化回归覆盖，但尚未完成独立 Chrome 的系统剪贴板端到端验收，不能把按钮显示“已复制”视为系统剪贴板的独立验证。

当前公开内容是开发预览，不是完整生产加固或商业认证声明。cloud2api 核心尚未指定独立许可证；公开可见不等于授予复用或再分发许可。OpenList 派生部分按其 AGPL-3.0 声明处理，详见 [OpenList 许可证文本](../openlist-patch/LICENSE)。
