# 真实网盘账号测试与社区反馈

网盘登录、凭据保存和续期由 OpenList 完成；cloud2api 只纳管已有存储并通过 API Key 开放文件操作。登录向导与平台前置条件见 [OpenList 补丁](../openlist-patch/README.md) 和 [平台矩阵](../openlist-patch/docs/PLATFORMS.md)。Local 存储和示例适配器可以验证流程，但不能证明真实网盘的登录、续期和限流行为。

阿里云盘、百度网盘、123云盘和 OneDrive 已收到用户登录成功反馈；Google Drive 以及不同账号类型、长期续期与失败恢复仍需补测。请将“登录成功”“读写成功”“续期成功”分别记录，不将其中一项扩展为全部验证通过。

## 准备

1. 使用自己的独立测试账号、存储和专用目录，不操作他人的文件，不在正在使用的存储上模拟凭据失效。
2. 按 [部署步骤](../README.md#怎么部署) 部署；服务地址与管理员凭据使用自己的配置，不将凭据写进测试报告。
3. 管理员从门户“添加网盘”进入 OpenList 向导；没有适配器的驱动可在 OpenList 原生后台创建，再回门户纳管。
4. 创建只授权测试盘与测试目录的临时 API Key，优先使用“通用”权限组。需要删除测试文件时再显式授予对应权限；不要通过“全部”绕过权限问题。

默认方式可能依赖第三方公开授权服务。Google Drive 等公共客户端不可用时，记录该限制或按平台文档使用自有应用，不提交第三方服务的令牌或完整回调地址。

## 通用测试清单

| 项目 | 检查内容 |
| --- | --- |
| 登录与保存 | 扫码、令牌粘贴或账号密码流程成功；结果页返回存储标识；OpenList 驱动初始化成功 |
| 返回与纳管 | 返回门户并刷新后能纳管；映射指向正确存储，纳管不自动扩大现有 Key 授权 |
| 授权发现 | `/v1/me` 只显示测试 Key 的网盘、根目录和权限 |
| 列目录 | 授权目录可读；根目录外的路径和未授权网盘被拒绝 |
| 小文件读写 | 上传有完整确认回执；读回字节与本地一致；官方客户端也能看到测试文件 |
| 工作台导航 | 进入子目录、返回上级、切盘时，上传目标与路径导航一致；目录加载失败不会显示旧目录统计 |
| 上传与分享 | 上传不自动公开；显式生成分享链接后，验证到期和权限行为 |
| 重启恢复 | 仅在独立测试实例重启后，核对映射、Key 授权和存储身份是否保留 |
| 自然续期 | 访问令牌自然过期后再次访问，单独记录驱动续期结果与观察时长 |
| 失效与重新授权 | 仅在可丢弃的独立测试存储上验证；重新授权后原映射、根目录和 Key 范围不变 |
| 清理 | 只删除本次创建的文件和测试存储，结束后吊销测试 Key |

文件操作示例见 [README](../README.md#有哪些-api)。上传完成依据是有效回执及大小、CRC-64/XZ、SHA-256 等结果，不是发送进度到 100%、HTTP 200 或出现文件元数据。

## 登录失败路径

只对独立测试存储执行适用项目，不适用或未测试的写明原因。

- 授权取消、拒绝、二维码过期及刷新。
- 格式错误和格式正确但无效的令牌，保存失败后的新建存储清理。
- 重复回调、重复点击保存及已有挂载路径冲突。
- 重新授权期间存储被另一管理员修改时，拒绝覆盖其配置。
- 重新授权失败后原配置是否保留或恢复。不要反复输入错误密码触发真实账号风控。
- 错误页和日志不包含密码、访问／刷新令牌、客户端密钥、授权码或完整回调。检查时避免将秘密写入命令行、Shell 历史或公开附件。

## 平台重点

| 平台 | 额外关注 |
| --- | --- |
| 百度网盘 | 公开应用和自有应用分别记录；观察长期续期；大文件临时空间和限流 |
| 阿里云盘 Open | 在线扫码、自然续期、重新授权以及授权服务不可用时的表现 |
| 123云盘 | 账号密码验证及风控；不要与 `123 Open` 的第三方 OAuth 流程混淆 |
| OneDrive | 个人、工作／学校账号分别记录；特殊云区域和 SharePoint 按驱动文档配置 |
| Google Drive | 公共客户端与自有应用分别记录；个人云端硬盘和共享云端硬盘分别测试 |
| 其他 OpenList 驱动 | 先在原生后台连接，再测试纳管与受限文件操作；上游支持不代表本项目已经验证 |

## 社区测试与 PR

欢迎帮助验证 OpenList 已支持但 cloud2api 尚未充分测试的登录项。提交脱敏测试报告或 PR 时，更新 [平台矩阵](../openlist-patch/docs/PLATFORMS.md) 的对应记录；新增适配器遵守 [贡献指南](../openlist-patch/docs/CONTRIBUTING-adapters.md)，并增加不依赖真实凭据的失败路径回归。

```text
日期：
版本（OpenList / connect / cloud2api 公开版本）：
平台 / 驱动 / 账号类型：
登录方式（扫码 / 粘贴令牌 / 账号密码 / 自有应用 / 原生表单）：
登录与纳管：通过 / 失败 / 未测
受限目录读写与上传确认：通过 / 失败 / 未测
重新授权 / 续期：通过 / 失败 / 未测
取消 / 过期 / 保存失败 / 恢复：通过 / 失败 / 未测
问题与复现步骤（不包含真实凭据、私人路径或文件内容）：
```

不要提交真实数据库、部署配置、原始请求／响应、完整日志或含授权二维码的截图。即使已对令牌打码，也要复核 URL、文件名、账号、路径和截图其他区域。疑似凭据泄漏应先撤销或轮换，不把原文贴到公开 Issue。
