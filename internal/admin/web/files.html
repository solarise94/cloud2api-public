这是什么密钥？和管理员登录有什么区别？

这里使用的是本实例签发的 API Key（sk-c2a-…，智能体接口密钥），不是管理员密码，也不是网盘（OpenList）的登录凭据。

能看到的网盘、可做的操作（浏览、上传、下载、删除、分享）完全由该 Key 的授权决定；没有授权的网盘不会出现，没有权限的操作不可用。需要签发或配置 Key、接入网盘，请前往管理门户。
